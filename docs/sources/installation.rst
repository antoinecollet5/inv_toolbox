=================
Installation
=================

Stable release
--------------

To install inv_toolbox, run this command in your terminal:

.. code-block:: console

    $ pip install inv_toolbox

This is the preferred method to install inv_toolbox, as it will always install the most recent stable release.

If you don't have `pip`_ installed, this `Python installation guide`_ can guide
you through the process.

.. _pip: https://pip.pypa.io
.. _Python installation guide: http://docs.python-guide.org/en/latest/starting/installation/


From sources
------------

The sources for inv_toolbox can be downloaded from the `Github repo`_.

You can either clone the public repository:

.. code-block:: console

    $ git clone git://github.com/antoinecollet5/inv_toolbox

Once you have a copy of the source, you can install it with:

.. code-block:: console

    $ pip install -e .[all]
